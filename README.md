# Zul Simulator

A comedic audio game for blind players, set on the streets of a Polish town.

You play a żul, one of life's street drinkers, on ulica Wesoła. Collect empties,
cadge change, dodge the police, keep your energy up, and try to get through the
day with your dignity roughly intact. It is played entirely by ear.

## Download

Get the latest version from the [Releases page](../../releases/latest).

Download the zip, extract it somewhere sensible (your Documents folder is fine),
and run **zul.exe**. Nothing to install.

## Playing

Arrow keys move you. Enter interacts with whatever you are standing at or beside.
Press H in game for the full how to play, which covers everything else.

The game speaks through your screen reader. NVDA, JAWS and SAPI all work.

Your saves live in your AppData folder, not the game folder, so updating the game
never touches them.

## Updating

The game checks for new versions when it starts and will tell you if one is
available. It asks before downloading anything.

## If your antivirus complains

It might. This is a false positive and it is not specific to this game.

Modern antivirus, Windows Defender especially, judges a program partly by how
many people have run it before. A newly built game that nobody has downloaded yet
has no reputation, so it sometimes gets flagged. This happens to Unity games,
to commercial titles on Steam, and to most small independent releases.

If Defender blocks it, you can allow the file through Windows Security under
Protection history, or add the game's folder to the exclusions list. If you would
rather satisfy yourself first, upload the file to virustotal.com and check it
against seventy odd scanners.

Please do not disable your antivirus entirely. Allowing this one folder is enough.

## Reporting bugs

Open an issue on this repo, or send the log. In game, the test menu can write a
log file which is genuinely useful for tracking down anything odd.
